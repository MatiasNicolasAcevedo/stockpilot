# StockPilot · client

SPA React + TypeScript + Vite con Material UI, TanStack Query, React Router y React Hook Form + Zod. En el stack la sirve el contenedor `client` (nginx), que es el único origen del navegador y reenvía `/api` y las rutas de login al server.
